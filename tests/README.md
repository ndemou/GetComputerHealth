# Tests

The contributor-facing testing documentation now lives in [`CONTRIBUTING.md`](../CONTRIBUTING.md).

Use that file for:

- test commands
- test categories
- conventions for new tests
- CI behavior

Quick reference:

- run all tests:
  `.\tests\run-all-tests.ps1`
- smoke run:
  `.\tests\run-all-tests.ps1 -Smoke`
